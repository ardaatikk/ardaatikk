## Featured Projects

### 🧬 Histopathology Cancer Detection

Deep learning pipeline for breast cancer metastasis classification in lymph node histopathology images, featuring slide-independent evaluation and explainable AI.

- ResNet-18 transfer learning
- Slide-independent 5-fold cross-validation
- Out-of-fold accuracy: **94.57%**
- Mean ROC-AUC: **0.9819 ± 0.0100**
- Grad-CAM & Integrated Gradients explainability
- Prediction error analysis (TP / TN / FP / FN)
- 44 automated tests and GitHub Actions CI

[View Repository](https://github.com/ardaatikk/histopathology-cancer-detection)

---

### 🎬 Human Action Recognition

Research-oriented deep learning pipeline for classifying human actions from video and pose landmarks, featuring controlled experiments and model stability analysis.

- CNN-LSTM, Pose-LSTM, and Mean-Pooled MLP architectures
- Subject-independent evaluation on the KTH Human Actions Dataset
- Pose detection and feature ablation studies
- Temporal order sensitivity and multi-seed stability analysis
- Held-out test accuracy: **80.83%** | Macro F1: **0.8061**
- 131 automated tests, GitHub Actions CI, and Docker support

[View Repository](https://github.com/ardaatikk/human-action-recognition)

---

### 💳 Fraud Detection ML API

End-to-end machine learning system for detecting fraudulent transactions using historical customer and terminal behavior.

- Leakage-aware behavioral feature engineering
- Chronological train / validation / test evaluation
- HistGradientBoosting classifier
- PR-AUC: **92.87%**
- F1 Score: **90.77%**
- FastAPI inference service
- Dockerized deployment
- 45 automated tests and GitHub Actions CI

[View Repository](https://github.com/ardaatikk/fraud-detection-ml-api)

### 🧍 Ergonomic Posture Monitor

Real-time computer vision system for personalized ergonomic posture monitoring using a standard webcam.

- MediaPipe Pose and Face Landmarkers
- Personalized posture calibration
- Real-time multi-feature posture assessment
- Actionable live feedback and session analytics
- Persistent JSONL session logging
